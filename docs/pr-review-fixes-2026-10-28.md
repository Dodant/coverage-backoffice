# PR 리뷰 수정 검증 — 2026-10-28

백오피스 PR #3와 백엔드 PR #16에서 재현된 세 가지 문제를 수정했다.

## 표지 카드 간 미저장 입력 유지

카드의 key에서 전체 갱신 revision을 제거하고 표지 ID를 유지한다. 카드별 저장 기준값을 분리해 수정 중인 폼은 서버 갱신으로 초기화하지 않으며, 저장한 카드만 서버가 반환한 값으로 정리한다. 겹치는 갱신 요청의 오래된 응답도 무시한다.

`tests/browser/cover-drafts.spec.ts`의 브라우저 회귀 테스트 4개가 통과했다. 다른 카드 저장과 이탈 경고, 대표·디자인 묶음 변경, 저장 실패·재시도, 늦게 도착한 갱신 응답을 포함한다. API는 테스트 범위에서 모킹하며 실제 도서를 변경하지 않는다.

## 관계 수정 잠금과 오래된 검토 상태 검사

번역서와 대상 원서뿐 아니라 수정할 이전 원서까지 동일 순서로 잠근다. 잠금 획득 후 1차 캐시의 값을 갱신하고 검토 ID를 다시 검사한다. 작품 묶음 변경 시 번역서에는 검색 이벤트만 발행해 잠그지 않은 자식 행을 UPDATE하지 않는다.

`RelationshipServiceConcurrencyTest`는 독립된 두 트랜잭션을 겹쳐 실행한다. 수정 전 코드에서는 교차 이동의 교착과 동일 번역서의 오래된 이동 덮어쓰기가 재현됐다. 수정 후 교차 이동은 모두 커밋되고, 동일 번역서의 경쟁 요청은 하나만 성공하며 다른 하나는 검토 충돌로 거절됐다.

H2 회귀 테스트와 별도로 전용 임시 PostgreSQL DB에서 같은 두 테스트가 통과했다. 실제 개발 데이터베이스는 테스트 대상으로 쓰지 않았으며 임시 DB는 종료 후 삭제했다.

## 업로드 전 픽셀 제한 검증

업로드 검증과 이미지 해시가 공통 4천만 픽셀 상한을 사용한다. 초과 파일은 래스터를 할당하기 전에 판정하고 HTTP 400으로 거절한다. 해시·썸네일 인코딩도 S3 기록 전에 완료한다.

`ImageUploadLimitsTest`에서 6,400×6,400 PNG가 10MB 미만이어도 업로드·해시 검증에 모두 거절되고 S3·업로드 기록 저장소는 호출되지 않는 것을 확인했다. 4천만 픽셀 경계와 곱셈 오버플로, 정상 800×1200 PNG도 검증했다.
